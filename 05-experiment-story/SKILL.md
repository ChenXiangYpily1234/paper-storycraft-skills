# 实验章节：用证据讲清科学故事 Skill

## 目标与工作范围

用于设计、重写、审查 Experiments/Evaluation 章节，使每个实验承担可识别的推理作用：**研究问题 → 公平的实验设置 → 观察结果 → 竞争解释的排除程度 → 适用边界**。适用于方法、系统、数据集、理论支持实验、复现和审计论文。

原始材料的“性能恢复、推荐指标、语言模型控制器、候选集合、非劣检验”等是**特定任务示例**，保留其中的严谨比较思想，但不得无条件植入其他领域。不要因字数、图表或页数偏好牺牲可复核的实验事实。

## 1. 实验从问题开始，而非从数据集开始

先建立**实验问题矩阵**：

| 科学问题 | 待区分的解释 | 所需对照 | 关键指标 | 判定准则 | 边界 |
|---|---|---|---|---|---|
| 主张是否成立？ | 改进来自核心机制还是额外资源？ | 公平强基线、资源匹配 | 任务主指标 | 差异/区间/检验 | 数据与预算 |
| 核心设计是否必要？ | 单个模块效果还是整体交互？ | 受控消融 | 主指标+代价 | 预先定义的变化 | 组件依赖 |
| 能否泛化？ | 只对某分布有效吗？ | 跨域/跨难度/跨规模 | 相应指标 | 一致性及方差 | 转移条件 |
| 现实代价如何？ | 准确率来自更高成本吗？ | 等预算比较 | 延迟、吞吐、内存、能耗 | Pareto/资源约束 | 硬件设置 |

上述仅为候选问题。每篇论文按实际 claim 选择，不强制安排固定数量的实验或设置。

## 2. 公共设置与特有设置分开

共同设置只定义一次：数据来源和版本、划分、指标、模型训练/评估预算、随机种子政策、统计检验、公共实现细节。只有特定实验需要的候选集合、额外访问权限、表示先验、工具调用限制、系统适配或时间窗口，放在该实验附近明确描述。

实验对象在第一次出现在表格前完成解释：**它是谁、拿到什么信息、能用什么算力、训练过没有、为什么是公平对照**。不要让读者先读一张充满未定义缩写的表再猜实验协议。

## 3. 指标要符合真正的计算对象

逐项明确：计算粒度（样本/用户/请求/设备/任务/种子）、分母、汇总函数、越大越好或越小越好、是否按组配对、是否有删失或过滤、是否涉及候选集合覆盖限制。

在确有必要时给出与**本论文实际协议一致**的数学定义；不能直接复制其他领域的 Recall@K、NDCG、F1 或生存分析公式而不检查条件。单目标推荐与多目标推荐的 Recall 语义可能不同；分类总体 Accuracy 与宏平均也不同。

区分：

- 描述性均值/标准差与推断性置信区间/假设检验。
- 相对提升与绝对差值、百分点差值。
- 原始样本数量与独立统计单位数量。
- “未发现显著差异”与“证明等效或非劣”。
- 多次试验中最优一轮与预定义汇总结果。

声称统计显著、等效、非劣或鲁棒时，应有相应检验规则和有效的不确定性估计，并说明多重比较与实验单位。

## 4. 对照不是越多越好，而是越能排除竞争解释越好

按论证需求建立**对照阶梯**：基本传统/简单基线 → 当前具有竞争力的强基线 → 资源/信息对齐对照 → 去掉关键模块的消融 → 排除数据泄漏或测试协议偏差的负对照。

对每个 baseline 问：是否同任务？同数据分割？相同可用输入、预训练知识与额外训练数据？相似推理预算、搜索范围和候选可见性？是否统一调参力度？是否复现原论文关键设置？性能更强也不一定等于比较公平。

若采用模块替代、随机化或打乱实验，必须说明什么被改变、什么被固定。成功改善可能来自“多了一条输入信号”而非作者声称的特定设计；要尽可能使用匹配信号量的控制实验区分。

## 5. 每个实验小节的故事

推荐自然顺序（灵活调整）：

1. **问题句**：这个小节判别哪个 claim？
2. **最小必要设置**：实验组/对照组、变量控制、评估对象及预算。
3. **主要发现**：读者应注意哪个图、表、指标及方向？
4. **解释**：证据支持哪一层结论？还有哪些替代解释？
5. **边界**：在哪种条件/组别没有出现该规律，意味着什么？

结果段落优先承担三件事：指出关键比较、解释可信的差异、回扣科学问题。不要将每个表格单元重复写一遍，也不要将所有数字藏在附录而只在正文留下笼统判断。

## 6. 多阶段研究要先画“证据链”

若研究有多个任务/阶段，先给出每一阶段验证什么：如“有效性→归因→鲁棒性→效率”或“数据质量→基准难度→泛化能力”。若两个实验验证的是同一个问题在不同环境下的表现，说明其共享的判断标准及本质差异，而不是依次堆叠实验章节。

一个典型逻辑是：主实验建立现象 → 公平控制排除更简单的解释 → 消融揭示组件贡献 → 分布外/资源实验明确适用范围。需要注意“消融改变多个变量”的情况下，不能把结果解释为单变量因果效应。

## 7. 机制、代理、工具与系统类实验的特殊审查（条件性启用）

只有当论文确实研究此类任务时检查：

- **机制比较**：区分“独立替代方案达到目标表现”和“目标模型内部替换机制”。
- **工具/代理系统**：说明工具列表、调用预算、工具返回信息、决策过程、是否在线更新、是否任务适配。
- **候选限制**：报告 candidate coverage 及其性能上限，避免把排序性能与召回覆盖混淆。
- **决策规则**：每个确定性策略都有可复现的选择条件，而非只写“固定策略”。
- **非劣/恢复**：阈值、单侧/双侧检验、统计单位、配对关系必须匹配，失败不能被倒置为目标机制必要的证明。
- **系统代价**：测量设备、负载、并发、缓存状态、批量大小与能耗/时间统计口径。

## 8. 图表承担不同任务

图适合显示趋势、分布、机制示意和边界；表适合准确的多模型比较、参数及统计判定。保留能够提供**独立证据**的图表，删除只是重复正文的装饰。图题要交代对象、比较条件、指标与必要的不确定性，不靠正文才能猜出曲线含义。

可视化的误导形式包括：截断纵轴掩盖差异、没有方差却暗示稳定、不一致的基线归一化、用人物图标代表比较次数、以单一颜色表达唯一信息、不同实验使用相同名称指向不同对象。

## 9. 稳健性、负结果与局限

稳健性分析围绕影响核心结论的关键扰动：随机性、超参数、任务难度、数据漂移、规模、噪声与预算。失败结果应明确陈述，不以“几乎所有”掩盖重要例外。

解释负面结果时要区分：没有统计证据、统计精度不足、方法在特定条件下确实下降、实验协议无法判别。避免“未能恢复 → 原机制必要”或“没有显著差异 → 两者完全一样”的逻辑跳跃。

## 10. 正文与附加材料的边界

**正文不可缺少**：中心 claim 的关键结果、评价协议、主要对照、公平性假设、重要统计判定、关键局限。**补充材料可承担**：更细的超参数、完整种子表、额外诊断图、实现清单。此区分按理解和可复核性确定，而不是以某一固定篇幅或会议模板决定。审稿人不打开补充材料也应能判断核心结论是否站得住。

## 11. 实验章节逐项压力测试

- [ ] 每个主实验能映射回题目、引言的一个明确主张。
- [ ] 控制组和对照组的输入、训练条件、调参和预算公平。
- [ ] 统计单位、置信区间、种子和分母明示。
- [ ] 无 test-set selection、训练/测试污染或候选泄漏。
- [ ] 未仅展示最有利的随机种子、数据子集或事后分析。
- [ ] 图表首次出现前已介绍实验对象，所有关键值与正文一致。
- [ ] 主要结果后面紧接解释，解释没有越过证据。
- [ ] 对失败、异质性、资源代价和边界采取诚实报告。
- [ ] 复现必需的信息有可追踪位置。

## 12. 输出格式

① 实验主张—证据映射表；② 公平性与混杂因素风险列表（按严重度）；③ 新的实验故事线与小节规划；④ 实验段落或完整章节修订稿；⑤ 应补的最小控制实验/统计核验（标明“建议”，不假装已经完成）；⑥ 结果和图表的引用对齐检查；⑦ 结论强度及外部有效性说明。

**最高优先级**：实验叙事不能取代严谨证据；如果缺少能区分两种解释的关键对照，必须明确指出研究主张尚未得到充分检验。
