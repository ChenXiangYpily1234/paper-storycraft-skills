# Paper StoryCraft｜论文故事性打造

本包将 **论文结构与语言叙事**、**科研结果图与 LaTeX 表格设计**、**可编辑 PPTX 科研图示**纳入一个审稿人可理解性框架。

**先读：[`总纲领.md`](总纲领.md)**。它统领所有子 Skill，并对“顺序讲明白研究问题”“首次出现术语就近解释”“全文同一概念同一名称”“论证链与真实证据一致”作出硬性规定。`WORKFLOW.md` 给出多 Skill 组合顺序。

## Skill 目录

| Skill 目录 | 职责 |
|---|---|
| `01-abstract-story/` | 摘要：问题、贡献、证据和边界 |
| `02-introduction-story/` | 引言：循序渐进引出研究动机 |
| `03-related-work-story/` | 相关工作：最相近工作与真实差异 |
| `04-method-story/` | 方法：定义、符号、模块和数据流 |
| `05-experiment-story/` | 实验：问题导向、公平对照、统计推断 |
| `06-discussion-conclusion-story/` | 讨论与结论：意义、局限和论证闭环 |
| `07-figure-story/` | 科研图示：概念图、结构图和证据可视化叙事 |
| `08-title-heading-story/` | 标题、子标题、图题和表题 |
| `09-consistency-validation/` | 终稿事实、主张、术语和图表一致性审计 |
| `10-latex-table-story/` | LaTeX 表格的证据表达、缩写和排版验收 |
| `11-research-plot-story/` | 根据真实数据绘制或修改科研结果图（含脚本） |
| `12-pptx-visual-story/` | 使用 PPTX 制作可编辑科研图示的叙事与检查指南 |

共 **12 个子 Skill**，从研究问题到文字、图表与证据，打造清晰连贯的论文故事线。

## 优先级和用法

1. 使用 `总纲领.md` 构建全稿故事线、术语台账与主张—证据账本。
2. 使用 01—06 与 08 修订文字结构与标题，结合 09 做事实和引文审计。
3. 使用 07 做图的论证设计；需要真实数值结果图时再用 11；LaTeX 表格用 10；可编辑 PPTX 图示用 12。
4. 逐项执行 09 的终稿审计，并模拟审稿人顺读全文；将首次术语阻塞与图表误读作为高优先级问题处理。

## 保留与清理说明

- 保留原文包 9 个章节/终审 Skill 的核心内容，增加共同总纲领约束。
- 保留 LaTeX 表格与结果图所需的 `assets`、`references` 和 `scripts`；公开版不包含许可限制再分发的第三方 PPTX 技术手册、脚本及参考资料。PPTX 叙事指南保留，技术工具需自行合法安装。
- 公开可见不等于所有内容均采用统一开源许可；本仓库未另行授予统一开源许可。
- 将表格包里的特定 AAMAS 项目路径与示例改成通用构建检查；不设置默认会议、年份、固定页数或参考文献起始页。
- 图表包包含若干原始领域示例和布局参考，**只能理解为示例**，不能自动当作新论文事实、默认数据或统计方法。
- 术语的解释应使用**论文撰写语言**；本 Skill 说明文字采用中文不意味着英文论文应改为中文。

## 限制

Skill 不能替代真实实验、权威文献核验或实际 PDF 阅读检查；缺少数据、源码、文献或渲染能力时必须说明未验证。不得为增强故事性伪造负结果、原因、实验数字、统计显著性或创新点。
