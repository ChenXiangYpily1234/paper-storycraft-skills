# 科研绘图

> **统领规范**：先读根目录 `总纲领.md`。图表中的新术语、坐标名称、缩写与系列标签必须在相邻正文、图内或图注完成必要解释，并与全文术语台账一致。

## 工作顺序

1. 确认目标论文、图号、真实数据源、指标单位、分组与统计口径。先检查已有脚本和产物；说明必要假设，不猜文件名或缺失数值。
2. 明确这张图回答的一个问题，再选图形。趋势用折线，离散比较用点图或柱图，分布用箱线或小提琴图，二维矩阵用热图。不要仅为美观更换会改变解读的图形。
3. 需要绘制或修改图本身时，从真实数据生成图，优先使用 seaborn。若仅修改正文位置或 caption，沿用已核验图文件，不为调整版面重新绘制。保留 Python 脚本、矢量 PDF 和预览 PNG；将输出接入原有 LaTeX 图环境。
4. 在最终印刷尺寸检查图和图注，编译论文，查看实际 PDF 中的字体、裁切、颜色、引用和浮动顺序。修复后重新检查受影响页面。

用户指定的协议、已有论文模板与期刊要求优先于以下默认值。只修改授权的图、脚本和必要正文；不顺带改实验结论。

## 数据与统计

- 没有真实数据时，先定位数据或请求缺失信息。示例数据仅用于测试工具，不能填入论文。
- 记录数据来源及处理逻辑；保留 dataset、seed、split、样本数、metric 和单位。不要将数据集均值、用户均值与 seed 均值混为一谈。
- seaborn 的自动聚合和默认误差条可能改变实验口径。对已汇总的数据使用 `estimator=None, errorbar=None`；误差区间只能来自真实统计结果。
- 明确百分比与比例：48.3% 的绘图值可以是 48.3；0.483 需明确转换，不能重复乘 100。
- “所有 seeds 均成立”的要求可能需要 worst-seed 汇总。只有协议要求时才使用最大或最小值，并在轴名、图注或正文说明，不能偷偷改成均值。
- 缺失值与实验失败不得当成零。不要平滑掉临界点、隐藏失败组或改变预先规定的阈值。

## 默认视觉规范

- 使用 seaborn 配合 matplotlib；白底、轻网格、简洁图例。颜色控制在可辨认的少数几组，同时用 marker 或线型区分系列。
- 按最终栏宽设计：双栏论文单栏图可从约 3.35 inch 宽、8 pt 字体起步，实际值服从模板。以缩放后的成图检查可读性，而不是只看大窗口。
- 导出 PDF 使用嵌入字体，如 `pdf.fonttype=42`；PNG 默认 300 dpi。保留矢量文字和线条，不将截图作为出版图。
- 图内文字使用论文一致语言和符号。标注量名及单位，分类标签按实际顺序排列；没有统计意义的顺序不要暗示连续趋势。
- 重合的零值或相同曲线不能被静默遮住。可采用不同大小的空心 marker、错开的注释或分面，不能移动真实坐标伪造差异。
- 检查 seaborn marker 边框是否能辨认，必要时显式设置为对应曲线颜色。
- 柱图通常从零起；截断坐标必须明显说明。折线范围可以按任务调整，但不得夸大效果。

## 图注、引用与论文集成

- 默认不在图内或图注放参考文献；数据集、模型和方法的文献放在正文首次介绍处，正文首次讨论图时添加 `Figure~\ref{...}`。期刊要求或用户另有指示时按其要求执行。
- 图注交代图的问题、对象、指标及必要统计限定；模型背景和长定义放正文。图注不是方法部分的副本。
- panel 标题与轴已经表达清楚时，caption 不必逐项重复“Panel (a) shows… Panel (b) compares…”。可用一句图的核心发现加一句汇总口径；真实的样本数、permutation 数、误差含义等必要限定仍须在图注或相邻正文可见。
- 区分 supporting attribution diagnostic 与 recovery test，保留其实际协议差异。用可读英文说明 uncapped histories、component analysis 等条件，避免把内部简称组合成难懂的长名词；不能把诊断性点估计改写为因果证明或 recovery 证书。
- 以 PDF 实际阅读顺序判断图位置，优先“问题与协议 → 图 → 解读”；边界图接对应 history/regime 段落，综合结论放在图后，避免图拖到下一节之后。仅在观察到问题时使用局部浮动控制，不随意改模板几何尺寸。
- 用户要求两张图保留正文时，保留两张图和各自科学问题；不要未经指示移入 supplement、合成四-panel 或改成跨双栏。两个问题如“证据来自哪里”与“在哪些情形失效”可分别用单栏图呈现。最终浮动仍须按逐栏阅读顺序检查。
- 省版面先删重复 caption/prose，再调整 panel 间距、legend 空白与尺寸，始终检查最终印刷字体。已有图清楚且版面够用时无需改图。如提供投稿版面规范，应依实际 PDF 核验；本通用 Skill 不预置任何页数指标。
- 图恢复正文后，检查图号、正文和 supplement 的引用。若它刚被移入 supplement，恢复时撤销此次产生的重复图环境，并保留补充材料的详细数据与协议说明。
- 若局部 `[t]` 将图推到下一页，且已有 `float` 包，可在实际验证后用 `[H]` 保证段落与图的顺序；不要机械应用于所有图，或靠全局负间距挤页。
- 优先沿用项目编译流程。独立 LaTeX 文档使用内置编辑器和编译工具；多文件项目若内置编译器不支持依赖，使用已存在的项目构建工具并报告限制。

## 资源

- 阅读 [图形选择与检查](references/plotting-patterns.md) 处理多 seed、重合曲线和渲染问题。
- `scripts/plot_ordered_series.py` 是有序类别折线的最小可复用模板，输入真实 CSV，显式禁止自动聚合。其他图型按实际数据写独立脚本，不强行套用。

## 完成交付

返回源数据来源、绘图脚本、PDF/PNG 路径及检查结果。明确哪些统计口径保持不变、是否仍有布局警告。只有真正查看成图后才能声称完成视觉检查；测试示例不能证明论文数据正确。
