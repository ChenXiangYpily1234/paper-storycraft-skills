# Paper StoryCraft：复制即用（中文）

把下面文本与你的**真实论文段落、目标期刊和已有证据**一起交给能够读取文件的 AI 助手。根据任务再提供对应 Skill 文件；不需要一次性加载 13 个。

```text
请将我提供的论文内容改成清晰、准确、有说服力的科学论证，而不是只润色语法。

任务模式：【仅诊断 / 改写指定段落 / 整章重构 / 投稿前审查】
目标章节：【摘要 / 引言 / Related Work / Methods / Experiments / 讨论 / 结论】
论文类型与目标读者：【请填写；未知则不要假定为 Nature】
不许改变：【数据、统计单位、表格、公式、图、label、真实引用键等按实际需要填写】

先确定研究问题、真正贡献、直接证据和适用边界。按技术机制而不是作者年份罗列 Related Work；
让 Methods 的设计选择有动机，让 Experiments 的主要比较有公平的协议和明确的解读。
突出真实优势，避免无谓自贬；保留影响结论的不利结果与重要限制。
方法、模型、benchmark、数据集分别核对来源，引用可以紧邻专有名称，不必统一放在句末。

仅输出我要求修改的范围及必要核验事项。没有看到的文献、数据、代码、PDF 不得称已验证；
无法查证的来源和实验结论必须标记“待验证”，不要伪造内容。
```
